University Graduate Forecasting Project (สมาชิกจำนวน 6 คน)
โปรเจกต์นี้ลองสร้างแบบจำลองที่ใช้ปัจจัย จำนวนผู้สำเร็จการศึกษาในแต่ละปี สาขาวิชา ประเภทสถาบัน และระดับการศึกษา ทำนายจำนวนผู้สำเร็จการศึกษา แล้วเปรียบเทียบกันว่าเทคนิคไหนทำได้ดีที่สุด 
สร้างแบบจำลอง 3 แบบใน RapidMiner ได้แก่ Decision Tree, Linear Regression และ Random Forest

วัตถุประสงค์
- ศึกษาลักษณะและโครงสร้างของข้อมูลการสำเร็จการศึกษาของนักศึกษาในประเทศไทย
- วิเคราะห์และคัดเลือกปัจจัยที่มีผลต่อจำนวนผู้สำเร็จการศึกษา
- ประเมิน เปรียบเทียบ และเลือกแบบจำลองที่ดีที่สุด โดยดูจากตัวชี้วัดทางสถิติ

ข้อมูลที่ใช้
- แหล่งที่มา: MHESI Open Data
- ขนาดข้อมูล: 16,720 แถว 12 คอลัมน์ ช่วงปีของข้อมูล: พ.ศ.2566
- ตัวแปรอิสระ: ข้อมูลพื้นฐานของนักศึกษา 5 ตัว ได้แก่สาขาวิชา, ประเภทสถาบันอุดมศึกษา, ระดับการศึกษา, เพศ, ปีการศึกษา
- ตัวแปรตาม: จำนวนผู้สำเร็จการศึกษาในประเทศไทย

จากสามเทคนิคที่ลอง Random Forest เหมาะที่สุดสำหรับข้อมูลชุดนี้ เพราะความคลาดเคลื่อนต่ำที่สุด (RMSE 33.995, MAE 14.884) และ R² สูงที่สุด (0.222)

ข้อจำกัด
ใช้ปัจจัยเพียง 5 ตัว แบบจำลองจึงอธิบายความผันแปรได้เพียงบางส่วน ถ้ามีข้อมูลเพิ่ม เช่น จำนวนผู้เข้าเรียนหรือข้อมูลด้านตลาดแรงงาน อาจทำให้แม่นขึ้น
ผลต่างระหว่างแบบจำลองในค่า RMSE ไม่มาก เมื่อเทียบกับความแปรปรวนระหว่างรอบการทดสอบ
